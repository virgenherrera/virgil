# Referencia

Material de consulta rapida: terminologia canonica, reglas de configurabilidad
y trazabilidad bidireccional entre la documentacion y el Principia.

## Documentos

| # | Documento | Que cubre |
|---|-----------|-----------|
| 1 | [Glosario](glosario.md) | Definiciones autoritativas de todos los terminos del Principia |
| 2 | [Que es configurable](que-es-configurable.md) | Que puede adaptar un proyecto y que declara el Principia como invariante |
| 3 | [Mapa de trazabilidad](mapa-principia.md) | Referencia bidireccional docs/ a principia/ con cobertura por capa |

## Guia de lectura

El glosario es util como referencia permanente durante la lectura de cualquier
otra seccion. El mapa de trazabilidad sirve para verificar que toda afirmacion
documental tiene respaldo constitucional y para identificar secciones del
Principia que aun carecen de documento dedicado.
